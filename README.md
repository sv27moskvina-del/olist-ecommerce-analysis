# Анализ маркетплейса Olist: продуктовая аналитика

## О проекте

Учебный проект по продуктовой аналитике на основе данных бразильского маркетплейса Olist. Цель — найти причины стагнации выручки и предложить решения для роста ключевых метрик.

**Бизнес-контекст:** Продакт-менеджер Петя переживает, что выручка маркетплейса стоит на месте несколько месяцев. Нужно провести анализ, найти проблемы и приоритизировать гипотезы для роста.

## Задачи

1. Оценить месячный retention с помощью когортного анализа
2. Определить наличие Product/Market Fit
3. Выделить 5 ключевых метрик для максимизации прибыли
4. Приоритизировать гипотезы роста с помощью фреймворка ICE
5. Подготовить отчёт с выводами и рекомендациями

## Описание данных

### olist_customers_dataset.csv
Таблица с уникальными идентификаторами пользователей:
- `customer_id` — позаказный идентификатор
- `customer_unique_id` — уникальный идентификатор пользователя
- `customer_city`, `customer_state` — география доставки

### olist_orders_dataset.csv
Таблица заказов со статусами и временными метками:
- `order_status` — статус заказа (delivered, canceled, unavailable и др.)
- `order_purchase_timestamp` — время создания заказа
- `order_delivered_customer_date` — фактическая дата доставки
- `order_estimated_delivery_date` — обещанная дата доставки

### olist_order_items_dataset.csv
Товарные позиции в заказах:
- `price` — цена товара
- `freight_value` — стоимость доставки

## Ключевые выводы анализа

### 1. Когортный анализ и Retention
- **Медианный retention 1-го месяца: 0.49%** — критически низкий показатель
- Из 1000 новых покупателей через месяц возвращается только ~5 человек
- Retention не улучшается между когортами, несмотря на рост базы клиентов

### 2. Product/Market Fit
**PMF отсутствует** по двум критериям:
- Retention < 5% (фактически 0.49%)
- Нет стабильности retention между когортами

**Причины:**
- Разовый характер покупок (товары не являются расходниками)
- Только 3% клиентов совершают повторные покупки
- Возможные проблемы с доставкой и post-purchase опытом

### 3. Ключевые метрики

| Метрика | Динамика | Вывод |
|---------|----------|-------|
| **GMV** | Плато ~850K с конца 2017 | Рост остановился |
| **MAU** | Плато ~6,200 с конца 2017 | Канал привлечения исчерпан |
| **Repeat Purchase Rate** | ~3% (растёт, но критически низкий) | Главная проблема |
| **ARPU** | Стабилен ~135 | Нет роста денежной вовлечённости |

**Вывод:** Дальнейший рост возможен только через повторные покупки, а не через привлечение новых клиентов.

### 4. Приоритизация гипотез (ICE Framework)

| Гипотеза | Impact | Confidence | Ease | **ICE Score** |
|----------|--------|------------|------|---------------|
| Исправить баг в процессинге | 5 | 8 | 6 | **240** 🏆 |
| Новый способ оплаты | 4 | 5 | 9 | 180 |
| Сократить время отгрузки | 1 | 10 | 4 | 40 |

**Победитель:** Исправление бага в процессинге заказов — устраняет ~970 отменённых заказов с июня 2017.

### 5. Метрики для A/B-теста

1. **Order Cancellation Rate** (целевая) — доля отменённых заказов
2. **Delivered Rate** (прокси) — доля доставленных заказов
3. **Average Delivery Time** (guardrail) — контроль клиентского опыта
